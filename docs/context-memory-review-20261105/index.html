数据进入软件前，先检查这三件事

角色不能改错

LongMemEval 是 user/assistant 历史。助手回答不能为了适配 QQ 被改成对方实际说的话。LoCoMo 两个人物则要显式映射到 self/contact。

答案字段不能进入产品

answer、has_answer、answer_session_ids、qa.evidence 和期望理解只给评审。用原始事件重建本系统自己的记忆。

改编后的分数是新协议

翻译、角色转换、追加“未发送/已发送”或“允许/不允许分享”等条件后，记录来源和变更；分别报告原协议与 QQ 改编版。所有同源会话变体在同一个 split，防止同母体泄漏。
