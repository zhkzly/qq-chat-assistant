# 关系聊天助手整体重构：实现与验收

本页保留2026-10-16候选`dbf630e`的当时验收结论；后续交接修复和启用状态见[2026-10-17修复记录](context-handoff-repair-review_CN.md)。旧语言失败不因后续功能修复而改判。

**工程重构已实现；持续聊天的内容质量尚未全部通过验收。候选保留在隔离分支，未合入main、未刷新真实QQ助手。** 不能把下面的功能通过数解释为自然性或恋爱效果。

## 实现了什么

目标是用户想联系或接话时，得到具体、自然、可展开的内容，帮助双方了解生活、表达自己和创造相处机会。当前实现形成一条实际消费链：

`实际QQ/用户原话 → 来源快照 → 核心/近期/按需选择 → 当前商量与具体材料 → 方法及内容规划 → 受限成稿 → 当前候选 → 实际收发/反馈`

| 部分 | 对目标的具体作用 | 本轮实际改变 |
|---|---|---|
| 上下文选择 | 当前内容和纠正优先，旧材料需要时可找回 | 原大builder拆为单一生效模块链；当前交流与72小时候选分开；按完整段和实际请求预算加载，标明遗漏；清除无关旧私下文字对检索query的污染 |
| 长期记忆 | 跨天保留已知生活、兴趣、共同旧事和明确偏好 | 复用SQLite、增量维护及更正链；常驻简洁有据核心与偏好；历史事实带日期及当前状态未知，不把旧职业当现职；原文和派生摘要用途分开 |
| 当前商量和材料 | 保住这次想说什么，并给规划器具体可聊内容 | ConversationWork派生当前意图、方向和指代；MaterialView区分实际交流、已说内容、自我材料、旧细节和安排；不新建永久机会库或好感分 |
| 帮助方法 | 从材料选择具体反应、跟进、分享、邀请或表意 | 八族共享一份操作指导，完整方法才带少量虚构例；不要求依次执行；示例不成为本次事实；反馈经验不自动升级为方法或长期偏好 |
| 成稿交接 | 当前分寸和真实意思不在最后一步丢掉 | 成稿只接获准原意、必要实际QQ、校验后的短方向与安全偏好；完整私人理由不传入；生成失败、关键澄清、当轮暂缓分别表示 |
| 候选与界面 | 用户先看到可用一句，新纠正不会仍推旧句 | CandidateSession绑定账号/好友、QQ修订、用户输入序号和计划摘要；新私下提交即撤旧主候选；实际发出后失效，编辑独立保留；自动产物不占据私下讨论主线 |
| 主动联系 | 没有新来信/新近况也能从已知细节开口 | “想和她聊”直接请求具体切口；“换个切口”带单条当前生成对象，明确要实质不同内容；不展开旧请求全体来源，不自动获得分享权限 |

72小时、5分钟候选有效期及各项预算都是可调整工程默认值，没有证明它们最优。没有新增Jev服务、逐条历史判断调用、多代理运行时、第二个记忆数据库或模型自动切换。通常规划与成稿各一次调用；补查、压缩、修复共用既有每任务预算。

## 怎样验

功能、合成界面、实际模型的虚构材料和真实桌面分别记录。最终89个测试文件、586项功能检查全部通过，递归语法检查通过。功能覆盖来源顺序、完整段及压力、旧干扰、偏好交接、改口/撤回、实际发送、取消、联系人切换、解释指代和候选过期。界面通过真实DOM操作检查当前候选前置、私下纠正、采用/复制、输入保留及自动任务抢占；它没有接入真实QQ，也没有调用provider。

最后的交叉审查发现：后台已经撤旧稿，界面在下次轮询前仍可复制。该窗口单独补红测：拦住网络请求使后台尚未开始，提交纠正或换切口，再调用已捕获的旧复制/采用回调；修复要求这些回调立即失效，同时普通输入和自动思考不随意撤稿。最终计数与文件摘要见[机器可读证据](relationship-refactor-evidence/verification.json)。

## 剩余问题与发布裁决

结构化交接、分层选择和候选失效能够解决已确认的工程偏差，但不能强迫规划器选择一个好反应。蛋包饭仍可能被写成泛问或制作方式核对；另一些句子主要是拟人复述、夸奖或关心收尾，独立评审对是否足够有内容也有分歧。把方法示例从技术追问改成轻松反应，并未可靠解决这些问题。

“突然想起”只需很小编辑就能修正，核心旧书切口本身有用；但它在本批明确禁止的未提供心理经过中，因此原稿仍不通过。不能据这个短语宣布整个产品无用，也不能以口语常见为由事后放宽验收。

本轮不继续增加提示词禁令、运行时judge或多模型循环，也不自动发布。后续改进需要用用户对具体候选的采用、编辑或弃用定位内容选择、规划与成稿的第一处偏差；模型比较也需要固定合理输入单列证据，不能由当前失败直接断言换模型一定有效。当前证据不足以宣称“始终有话可聊”已稳定实现。

真实QQ现有进程仍加载旧版本。本轮没有关闭QQ、重启服务、改安装、发送消息或覆盖未发送输入；合成浏览器和虚构实际模型均不能替代新版桌面验收。后续启用需重建worker/controller，不能用旧实例方法热替换冒充新CandidateSession已生效。

## 设计依据

收藏长文已保存在现有OpenViking资源中，详见[方向和生命周期记录](relationship-assistant-refactor-note_CN.md)。本轮采用混合预载/即时检索、结构化外置记忆、私下讨论压缩、方法按需加载、隔离探索上下文及显式来源覆盖；不把文章的近似公式和百分比当作质量定理。[Anthropic原文](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)、[Lost in the Middle](https://arxiv.org/abs/2307.03172)提供工程参考，不能证明短上下文必然更会聊天。

人际研究对回应具体分享、真实自我表达和相互了解提供有限依据，适用范围和反例见[独立反方提案](refactor-goal-acceptance-proposal_CN.md)。研究不支持用回复数、画像完整度或内部评分证明对方产生恋爱兴趣。
