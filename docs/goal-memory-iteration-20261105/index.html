已观察的因果链

确定性与适用时间混合

原文明确、来源完整，却因持续时间未知归入“不确定”。改为保留“有据报告”，单独显示适用期限。

未申报的错误个人事实漏检

只验证模型自行申报的素材，不能发现它未申报的“我从没做过”。增加最终可见回答核对，并保留必要澄清出口。

传输、读取与准入不一致

当前请求的部分送达信息丢失；续读正文虽然到达模型，下游仍只对主片段验证。统一精确范围、来源版本和权限消费。

摘要得到多余行动权

数量表达被识别成时间，背景声明又产生接受邀约指导。摘要只导航；同一个有效任务条件控制提示、格式与验证。

候选与决定

检查器也会误判：B002 将合法分享误报为隐私问题，拒绝了本可完成的帮助，已拒绝该候选。后续版本区分程序许可、真实限制、事实断言与普通建议；问句仍可能泄密。
观测修正与证据边界

可选压缩失败后，产品会降级到确定性上下文继续回答。旧测试器把被捕获的内部异常判为整次求助失败；v4 保留异常痕迹，并以外层请求结局判定。旧结果保留，新条件另目录重跑。

缺失步骤也曾出现引文验证矛盾：缺失标记通过当前结果检查，却在自己的历史前缀检查中被拒。已通过正反例修复，既有评审不改语义。

本报告包含真实选定模型 HTTP、虚构 QQ 原生边界事件和 UI 消费字段投影。它不是桌面实机集成、并发摄入或重启持久化证明。主程序尚未因局部候选自动部署。

JEV 和公开 benchmark 的位置

本轮没有引入 JEV，也没有取得同输入速度优势证据。受控关系判别集为之后的对比保留接口；程序继续管理来源、版本、许可和提交。公开数据集可以提供原始历史种子，接入前仍需固定许可证、来源版本与项目场景映射。
