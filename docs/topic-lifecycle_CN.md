# 本地结束与移除话题

原来的“这件事聊清楚了”只把结束指令填进私下输入框，需要提交给模型才能改状态。模型返回429时，话题继续显示。这是按钮和状态操作之间的实现缺口。

现在“这件事聊清楚了”直接在本地标记完成，退出当前话题；“移除这个话题”直接移除这项话题记录。二者都不需要模型响应，也不提交或修改输入框文字。调整方向仍可先在输入框补充具体意思。

操作绑定当前账号、好友、话题ID与版本。旧版本和其他会话的请求拒绝，正在生成的过时结果取消，较早的轮询不恢复旧卡片。完成的话题仅作历史导航；移除后不再出现在当前/保留话题列表。当前焦点清空、其他状态保留并标记待复核，旧讨论缓存失效。结束的是这次私下讨论目的，实际QQ、长期关系目标、对方兴趣记忆、私下原话和未发送草稿保留。

合成与功能验证和实际桌面验证分开记录在[验证记录](topic-lifecycle-evidence.json)。操作本身没有模型调用，后续已授权的正常后台整理仍可处理本地操作来源。
