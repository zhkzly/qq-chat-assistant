# 使用说明

## 持续私下助手

在助手主区域直接说目标、近况、困惑或明确的保存/更正要求。目标和素材可从自然讨论保存，表单是可选编辑入口；需要参考表达时可以说“就按刚才那个”或点选一个方向。快速回复和自动建议也共用长期背景。背景区可搜索以前说过的事、查看整理状态、确认或撤销具体修改。所有内容按当前账号和好友隔离，仍由你在 QQ 手动发送。完整说明见 [上下文管理](context-management_CN.md)。

## 打开与选择好友

在应用菜单打开「QQ 聊天助手」，或在 `~/pycodes/qq-chat-assistant` 运行 `npm start`。按 QQ 原来的流程登录，在好友私聊输入工具栏点击「✦ AI 建议」，也可按 `Ctrl+Shift+A`。再次打开会复用助手窗口。

填写好友 QQ 号后点「连接会话」即可切换。部分好友的身份或历史还没有进入本机缓存，需要先在 QQ 打开该私聊再连接；助手不能承诺读取腾讯服务器的全部历史。错误、空记录和本机已有缓存分别显示，不再一直假加载。

## 浏览、图片与表情

首屏显示最新 100 条，向历史面板顶部滚动或点击「查看更早消息」会继续展示已经缓存的记录，每次 100 条。「从 QQ 读取更早记录」才会请求新的历史页；两者用途不同。后台首轮最多读取 20 页，进一步读取最多 200 页。本次指定好友的 739 条记录包含双方内容。

图片的「查看图片」只读取本机 QQ 已缓存文件。尚未缓存时先在 QQ 查看原图后重试。本次已经实测一张该好友的本机缩略图可显示，但不保证所有旧图片仍可用。图片预览与模型看图是两个独立操作。

已知 QQ 表情用相近 Unicode emoji 显示，和原版 QQ 图案可能不同。未知表情显示名称或编号。新生成的建议不再保留 `[表情]` 占位；模型需要表情时使用可复制的 Unicode emoji。已生成的旧建议需重新生成才会更新。

## 建议、复制与填入 QQ

填写「你希望怎么回应」，生成三条参考。每条都有「复制这条」和「采用到草稿」。草稿可以修改，再点击「复制回复」或「填入 QQ 输入框」。草稿按账号和好友保存在本机，未发送草稿不算聊天消息。

回填前直接核对当前 QQ 联系人及输入框，写入前再核对一次；同一好友开了多个窗口时优先使用点击「✦ AI 建议」的那个窗口。不能确认时会取消。QQ 输入框已有文字时先询问是否替换。回填不会触发 QQ 发送；发送按钮和回车由你操作。

连续收到多条消息时，默认把最近最多 8 条连续来信作为回应重点，结合其余上下文按话题合并回复。可以勾选某一条或多条「重点回复」（最多 8 条），旧消息也会优先进入本次模型上下文；点击「回到最新消息」取消手动重点。选中重点后新来信不会擅自改变所选目标。

这里选择的是 AI 回应重点，不会生成 QQ 原生引用框。需要针对某条消息引用回复时，在 QQ 对原消息选择「回复」，再复制建议到该输入框；发送仍由你操作。

收到或确认已发送的新记录会更新上下文。「新消息自动更新建议」只更新参考文本。关闭助手窗口会暂停自动模型生成。

## 模型设置与看图

顶部直接显示 API 配置与模型下拉框；「刷新列表」从所选服务读取 `/models`。图片生成专用 ID 会标注并禁选；列表不代表每个 ID 都有调用权限或支持看图。

「⚙ 模型设置」可新增多套具名配置，各自保存地址、密钥、模型和图片能力。原配置原地址下，密钥留空才会保留；更换地址必须重新填密钥，免密本地服务则明确勾选「无需 API Key」。不提供模型列表的服务可手动填写模型 ID。目前支持 OpenAI 兼容 Chat Completions 接口，原生 Claude/Gemini 接口需要经过兼容代理。

当前配置使用 `gpt-6.1-sol` 和已有 `http://127.0.0.1:8317/v1` 代理。模型本体不是由本项目部署；本机代理负责连接其配置的上游服务。

文字授权限定当前 QQ 账号、好友、模型、API 地址。页面显示目的地，点击「允许当前会话使用这个模型」后才能生成。此前自动审批拒绝过缺少目的地授权的真实聊天测试，因此保留这道授权门；当前用户已通过页面授权的会话可以正常使用，不代表其他会话已获授权。

模型看图还需：在设置确认所选模型支持图片；在记录里勾选「本次让 AI 看此图」（最多 3 张）；勾选并提交图片授权。只把所选图片和本次文字上下文提供给模型。已经用虚构蓝色方块验证当前模型视觉请求返回成功，没有用私人 QQ 图片做模型测试。

「查看上下文」会显示本次文字选择、字符预算、图片选择及图片授权状态，不会执行模型请求。实际选取规则见 [上下文管理](context-management_CN.md)。

## 导出与停止

「导出 JSON」或「导出文本」保存当前账号/好友的本机可访问记录，带消息 ID、双方方向、时间和覆盖范围，不含草稿或私有媒体路径。文件可能包含私人聊天，项目不会上传它们。

暂停建议：取消自动更新或关闭助手窗口。退出助手版 QQ：从 QQ 菜单退出；之后照常启动原 QQ。原安装 `/opt/QQ/qq` 未修改；项目 `data/` 保存本机记录、配置和运行时，已排除 Git。诊断 `npm run diagnose` 不输出聊天文本或模型密钥。
