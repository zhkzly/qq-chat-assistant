# 独立盲评：9 对接话输出与 2 个当前目标样本

本评审只读取 `/tmp/qq-refactor-paired-blind-20261016.json` 及后来提供的 `/tmp/qq-refactor-topic-blind-20261016.json`。未读取项目源码、设计、其他评审或配对 key，未参与实现，未调用真实模型或 QQ。A/B 只表示每例中的位置，不推断版本；不同样本的 A 或 B 不能视为同一个系统。

评判目标是：帮助用户与网上认识、有好感的女生自然接近，在想接话时得到具体、可用、能接着聊的内容；尊重当下明确收尾，不虚构当前事实。不因问号更多、篇幅更长或更像调情而加分。单句回应可以合格；必要的私下澄清也可以比立即拟稿更有用。

## 评分口径

每维 0–2 分，2 为满足当前样本需要，1 为部分满足或有明显可改处，0 为失配。

| 维度 | 观察内容 |
| --- | --- |
| 处境 | 是否理解最新进展、当前忙闲和仍适用的本轮要求 |
| 意思保真 | 是否保留双方真实表达及用户意图，未知事实是否仍为未知 |
| 具体帮助 | 是否给出可直接编辑使用的内容，或提出会实质改变回复的必要澄清 |
| 自然互动 | 是否有贴近这件事的反应或延展，避免纯复述、模板夸奖和机械采访 |
| 双方选择 | 是否保留用户决定事实和行动的权利，尊重对方的当下边界 |

“硬失败”指直接违反明确约束或把未知事实当成已知，不能用其他维度的优点抵消。“小改”指表达基本可用，但对本目标仍有具体改进空间。总分只是粗粒度辅助，不替代逐对判断。

## 原 9 对样本内结论与边界

- 9 对中，B 更好 3 对，持平 6 对，A 更好 0 对。A/B 已逐例打乱，**不能把这个计数转成任何版本胜率**。
- 18 条响应中：采用 14 条，小改 3 条，重写 1 条；复核后可证实的硬失败为 0 条。sample-4-1 A 的问题是与本轮偏好贴合较差，不能从单个问句证明“连续追问”。
- 多数差异只是表达质量或延展方向；最明确的质量差距来自回应用户本轮具体要求的程度，而不是更会提问、话更多或更像调情。
- 这 9 对样本对未知图片、当前收尾、邀请事实缺失和本轮纠正有一定覆盖。但它们主要是对方已经分享内容后的接话，尚不足以验证用户主动想联系时能否获得新话题，也没有覆盖旧收尾过期后主动重联的输出。后面追加的 topic-1 单独检验了一个旧收尾后的重联切口。
- 这些是同一批虚构输入上的实际模型输出评审。结果只适用于这些输出，不能证明现实关系更亲近、对方会回复，或真实 QQ 桌面流程已经完成集成。

## 初判与复核记录

初次独立评审将 sample-4-1 A 评为 `0 / 1 / 1 / 0 / 1 = 3`，建议重写，并判硬失败。依据是我将“先别连续追问……轻松接……就好”解释成这一轮需要一句不追问的反应。

协调者随后要求区分硬违约与不自然，并指出原文没有禁止每一个问句。我据此只复核该输入和输出的证据强度，未接触配对 key 或其他评审。最终改为 `1 / 2 / 1 / 1 / 2 = 7`，仍建议重写，硬失败改为否：单条制作分类问题自然度和偏好贴合较弱，但没有可见的连续追问链，不能证明严格违约；问法本身没有造事实或替双方做决定。逐对胜负保持不变。此更正保留初判，避免把语义上的较强解读伪装成客观已证实的约束违反。

其他样本使用同一标准：有明确、适切承接作用的单个问题可以合格；没有问号也不会自动获得自然度或展开性满分。

topic-1 提供的是温和的旧话题重联入口，作用是让她有机会补充旧书的新发现，不是宣称一句话能让关系升级。“回头讲给我听”仍需用户按自己的口吻决定是否保留；当前句子有条件且不限定时间，没有足够证据认定催促或布置任务。它主要依靠对方补充内容，展开幅度有限，但在用户没有新日常事实的前提下，是可直接使用且不虚构的具体切口。

topic-2 的“画面感太强了”本身较常见，但前面是对这次副本场景的具体反应，后面只跟进一个相关后续，因此整句不等于模板夸奖或机械采访。这里不因有问句而加分，而是因为该问句继续的是她刚刚主动讲出的同一个事件，并允许她补完结局。

新增样本分别支持“没有新 incoming 时可从已知细节重联”和“对普通分享给具体后续”这两个有限判断。两条均为采用、无可证实硬失败；它们不能说明其他主动联系场景同样可靠，也不能说明现实关系效果或真实桌面集成已经验证。
