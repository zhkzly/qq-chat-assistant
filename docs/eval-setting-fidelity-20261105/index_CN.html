审查后必须守住的质疑

原文匹配，不等于历史调用真实发生过

准备回执明确标注归档 user/assistant 数量，且 entire_history_reexecuted:false。空库流式的执行声明由独立 setting receipt 提供；不能只改一处标签来宣称 E2E。

pending 清零，不等于理解准确

保留 journal、semanticPending、待提案、错误和恢复工作。固定时间提问，正常空闲不足时允许未完成；不强行预整理后再宣称正常调度成功。

候选给对了，不能证明实际检索给得对

组件输入有意固定。产品候选召回、实际交付、模型正确使用必须分开观察。四个关系轴和可兼容解释也不要求产品采用某种内部 memory schema。

JEV 的局部速度不等于整套系统更快

先确定替代的是哪段 Luna 工作；记录批大小、缓存、网络、重试、回退和整个整理成本。本轮没有 JEV 对照结果，不能宣布加速。
