included. Model settings hashes bind the read-only configuration.

Original identities and incomplete states are preserved. The three-case batch,
matched current-material control and private-feedback-only probe are distinct
experiments; do not combine them into a passing frozen-case result. The private
probe changes the request to isolate feedback from drafting and is not dataset
acceptance. No packet is an unseen benchmark or real relationship evidence.

See docs/eval-fidelity-v2-verification_CN.md for the actual semantic review,
failures and calibration limits. The raw original run diagnostics remain in the
local paths recorded by the verification manifest.

its original body SHA256 and projection note; observable content/tool calls and
response metadata remain. Original local response files are not overwritten.
